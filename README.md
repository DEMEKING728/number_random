# 数字配置ツール(説明 by ChatGPT)

1〜42の数字を、7行×6列の盤面にランダムに配置するツールです。

コマンドを入力することで、数字を特定の位置に固定したり、指定した範囲内にランダム配置したりできます。

## 主な機能

- 1〜42の数字を重複なく配置
- 指定した位置への固定配置
- 前10マスへのランダム配置
- 指定した範囲へのランダム配置
- 複数の長方形を組み合わせた範囲指定
- 重複する範囲を統合し、各マスの当選確率を均等化
- 配置できない場合のエラー表示

## 使い方

1. 数字配置ツールをブラウザで開きます。
2. 入力欄にコマンドを入力します。
3. 「表示」ボタンを押します。
4. 指定した条件に従って、7行×6列の盤面が生成されます。

コマンドは**1行に入力し、カンマ（`,`）で区切ります**。

### 入力例

```text
s:A1;12,f:5,r:B2-D4;33
```

この例では、次のように配置します。

- `s:A1;12`：A1に12を固定配置
- `f:5`：5を前10マスの空いている位置に配置
- `r:B2-D4;33`：B2〜D4の長方形の範囲から、33をランダムに配置

残りのマスには、使用されていない数字がランダムに配置されます。

---

## コマンド一覧

### 1. `s:` — 指定位置への固定配置

指定したマスに数字を固定配置します。

**構文**

```text
s:位置;番号
```

**例**

```text
s:A1;12
```

A1に12を配置します。

複数の位置を指定する場合は、カンマで区切ります。

```text
s:A1;12,s:G6;30
```

A1に12、G6に30を固定配置します。

#### 位置の指定方法

位置は、行をA〜G、列を1〜6で指定します。

| 位置 | 意味 |
|---|---|
| A1 | 最上行・左端 |
| A6 | 最上行・右端 |
| G1 | 最下行・左端 |
| G6 | 最下行・右端 |
| C3 | 上から3行目・左から3列目 |

`A1`形式のほか、`1A`形式でも指定できます。

例えば、`s:A1;12`と`s:1A;12`は同じ位置を表します。

### 2. `f:` — 前10マスへのランダム配置

数字を、前10マスのうち空いているマスにランダムに配置します。

**構文**

```text
f:番号
```

**例**

```text
f:25
```

25を前10マスの空いている位置に配置します。

前10マスは、次の位置です。

- 最上行の6マス
- 2行目の左から2〜5列目の4マス

合計10マスです。

`s:`や先行する`f:`によって埋まっているマスは、配置候補から除外されます。

### 3. `r:` — 指定範囲へのランダム配置

指定した長方形の範囲から、数字をランダムに配置します。

**構文**

```text
r:位置-位置;番号
```

**例**

```text
r:A1-C3;20
```

A1とC3を対角線の両端とする長方形の範囲から、20をランダムに配置します。

対象となるのは、A1〜C3の9マスです。

#### 複数の範囲を指定する

1つの`r:`コマンド内で、複数の長方形を指定できます。

**例**

```text
r:A1-C3;E4-G6;20
```

A1〜C3とE4〜G6を合わせた範囲から、20をランダムに配置します。

範囲はセミコロン（`;`）で区切り、最後に配置する数字を指定します。

#### 範囲の指定順序

長方形の対角線の両端は、どちらから指定しても構いません。

例えば、次の2つは同じ範囲です。

```text
r:A1-C3;20
r:C3-A1;20
```

#### 重複する範囲の扱い

複数の長方形が重複している場合、重複するマスを1つにまとめてから抽選します。

**例**

```text
r:A1-C3;B2-D4;20
```

この場合、A1〜C3とB2〜D4の範囲を統合します。

重複部分のマスが二重に数えられることはありません。抽選対象となる各マスの当選確率は均等です。

また、すでに数字が配置されているマスは抽選対象から除外されます。

---

## 配置の優先順位

コマンドは、次の優先順位で処理されます。

1. `s:` — 固定配置
2. `f:` — 前10マスへのランダム配置
3. `r:` — 指定範囲へのランダム配置
4. 自動配置 — 残りのマスをランダムに埋める

### 同じモードを複数指定した場合

同じモードのコマンドが複数ある場合は、**入力順が早いコマンドを優先**します。

**例**

```text
r:A1-B2;10,r:C3-D4;20,r:E5-F6;30
```

この場合、最初に10、次に20、最後に30の配置先を決定します。

先に配置された数字やマスは、後続のコマンドでは使用できません。

### 異なるモードを組み合わせる場合

入力欄に記述した順序にかかわらず、モードごとの優先順位に従って処理されます。

**例**

```text
r:A1-C3;33,f:5,s:B2;12
```

この場合でも、処理順序は`s:`、`f:`、`r:`です。

---

## エラーと注意事項

配置条件を満たせない場合は、エラーメッセージが表示され、盤面は生成されません。

### 1. 配置先がすべて埋まっている

`f:`の前10マスや、`r:`で指定した範囲がすべて埋まっている場合、配置エラーになります。

例えば、A1〜B2の4マスがすべて固定配置されている状態で、次のコマンドを指定した場合です。

```text
s:A1;1,s:A2;2,s:B1;3,s:B2;4,r:A1-B2;20
```

指定範囲に空いているマスがないため、20を配置できません。

### 2. 同じ数字を複数回指定する

同じ数字を複数のコマンドで指定することはできません。

例えば、次の入力はエラーになります。

```text
s:A1;12,f:12
```

12がすでに使用されているため、`f:12`を実行できません。

### 3. 固定位置が重複している

同じマスに複数の数字を固定配置することはできません。

例えば、次の入力はエラーになります。

```text
s:A1;12,s:A1;20
```

### 4. コマンドの形式が正しくない

位置・数字・範囲の指定が正しくない場合は、エラーになります。

数字には1〜42を指定してください。

## 入力例まとめ

| やりたいこと | 入力例 |
|---|---|
| A1に12を固定配置 | `s:A1;12` |
| 25を前10マスに配置 | `f:25` |
| A1〜C3に20を配置 | `r:A1-C3;20` |
| 2つの範囲から抽選 | `r:A1-C3;E4-G6;20` |
| 重複する範囲から抽選 | `r:A1-C3;B2-D4;20` |
| 固定配置とランダム配置を併用 | `s:A1;12,f:5,r:B2-D4;33` |

---

## 仕様

- 盤面：7行×6列、合計42マス
- 使用する数字：1〜42
- 数字の重複：なし
- 配置方法：固定配置・範囲指定・ランダム配置
- コマンドの区切り：カンマ（`,`）
- 範囲内の区切り：ハイフン（`-`）
- コマンド内の区切り：セミコロン（`;`）
- 位置の形式：`A1`〜`G6`、または`1A`〜`6G`
- 優先順位：`s:` → `f:` → `r:`
- 同一モード内の優先順位：入力順
- 配置条件を満たせない場合：警告を表示し、生成を中止
